# Локальный телефон

Версия 1.1.0. Телефон внутри сцены: письма, лента, люди, снимки, заказы и текстовый звонок. Ответы пишет модель клиента. Чужих лент, карт и хостингов картинок нет.

Кнопка обновления в Таверне — это её `git pull` этого репозитория, не запрос телефона.

## Установка в SillyTavern

Кнопка обновления есть только у установки из git.

1. «Расширения» → «Установить расширение».
2. Адрес: `https://github.com/Prohor-godslayer/local-social`. Ветка `main`.
3. В «Управление расширениями» карточка «Локальный телефон», версия 1.1.0.
4. Включи «Уведомлять об обновлениях расширений», если пункт есть.

Кнопка ☎ у края чата. Пункт меню — «Локальный телефон».

Папку без git в `data/<пользователь>/extensions/local-social` удали и поставь по ссылке.

### Когда Таверна говорит, что нужно обновить

`"version": "1.1.0"` и `"auto_update": true`. Сравнение с `origin/main`. Кнопка по-английски — **Update available**, по-русски — перевод из языкового пакета. Нажатие делает `git pull`.

## Установка в Tavo

1. Скачай `tavo/local-social.tpg`: https://github.com/Prohor-godslayer/local-social/blob/main/tavo/local-social.tpg
2. Импортируй плагин. Сетевого права нет. Нужны ввод, сообщения, переменные, файл и генерация.
3. Открытие: кнопка ☎, действие ввода «Локальный телефон», боковая панель.

Новую версию ставь повторным импортом `.tpg`. Версия плагина 1.1.0.

## Как пользоваться

Телефон привязан к чату. Ты и персонаж уже есть в контактах, имена берутся из чата.

1. Письма. Выбери собеседника, напиши текст, «Отправить». Твоя строка сохраняется сразу, затем модель пишет ответ от его лица: одно короткое сообщение, без звёздочек. Пока она думает, не шли новое сообщение в основной чат.
2. Люди. Добавь NPC по имени: курьер, сестра, сосед. Ему можно писать отдельно, он не становится персонажем чата. Крестик удаляет контакт и его переписку.
3. Лента. Пост от себя или от персонажа. «Комментарий персонажа» просит модель одну-две фразы под этим постом.
4. Снимки. Файл с устройства уменьшается на месте до 1280 px по длинной стороне и лежит в браузере. В чат уходят имя и время, не сама картинка. Другой браузер галерею не увидит.
5. Заказы. Что и заметка. Строка попадает в следующий промпт как уже случившийся заказ. Доставки с чужого сайта нет.
6. Звонок. «Позвонить» просит модель 4 реплики строками «имя: текст». Голоса и линии нет. В промпт попадают последние реплики телефона, лента и последний заказ, чтобы персонаж не пересказывал меню, а опирался на то, что уже было.

Ответ короче 1 символа, длиннее 500 или со словами «промпт», «модель», «ассистент» не записывается.

## Где лежат данные

SillyTavern: метаданные чата, `local_suite.social`, объект `phone`. Картинки — IndexedDB `local-social`.

Tavo: `lx_social_chatbag` по id чата. Картинки — та же IndexedDB браузера, в котором открыт Tavo.
