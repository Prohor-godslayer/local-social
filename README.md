# Локальный телефон

Телефон внутри сцены: письма, лента, люди, снимки, заказы и текстовый звонок. Ответы пишет модель клиента. Снимки сжимаются на устройстве и остаются в IndexedDB. В данные чата попадают переписка и подписи, не сами файлы картинок.

Внешние ленты, чужие картинки и облачный аккаунт отсутствуют.

## SillyTavern

Скопируйте репозиторий в `data/<пользователь>/extensions/local-social`. Панель: кнопка у края чата и пункт «Локальный телефон».

## Tavo

Импортируйте `tavo/local-social.tpg`.
